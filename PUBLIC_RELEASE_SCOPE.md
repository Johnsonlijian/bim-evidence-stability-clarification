# Public release scope

This repository is the public reproducibility package for the R10 manuscript *Decision-stable automated code checking under conflicting BIM evidence*. Release v0.1.0 is archived on Zenodo under DOI [10.5281/zenodo.23361167](https://doi.org/10.5281/zenodo.23361167) and developed at https://github.com/Johnsonlijian/bim-evidence-stability-clarification.

Included: frozen analysis code, reporting scripts, pre-registration and deviations, derived evidence ledgers, compressed experiment records, aggregate results, editable tables, vector figures, data-source links and redacted lineage summaries.

Excluded: raw third-party IFC files and archives, active manuscript and cover letter, submission forms, internal rounds and logs, the companion-corpus lineage index, credentials, private author files and any data whose redistribution terms are unclear.

The companion-corpus index is retained locally for the lineage audit and can be supplied to an editor if requested; it is not copied into a public repository because it contains internal file paths.

## Licence

The release uses a split licence. Source code in `src/` and `scripts/` is released under the MIT licence (`LICENSE`). Derived data, result tables, figures and documentation are released under the Creative Commons Attribution 4.0 International licence (`LICENSE-DATA`). Raw third-party IFC models are not redistributed and remain subject to the terms in their own model cards, listed in `DATASETS_AND_LINKS.csv`.
