# Public release scope

This local repository is the public-reproducibility candidate for the R10 CACAIE manuscript. It is not yet a published GitHub repository or Zenodo record.

Included: frozen analysis code, reporting scripts, pre-registration and deviations, derived evidence ledgers, compressed experiment records, aggregate results, editable tables, vector figures, data-source links and redacted lineage summaries.

Excluded: raw third-party IFC files and archives, active manuscript and cover letter, submission forms, internal rounds and logs, the companion-corpus lineage index, absolute workstation paths, credentials, private author files and any data whose redistribution terms are unclear.

The companion-corpus index is retained locally for the lineage audit and can be supplied to an editor if requested; it is not copied into a public repository because it contains internal file paths.

Before external publication, the author must select a code/data license, confirm the related-manuscript disclosure, create or verify the intended GitHub repository, and mint a Zenodo record if an archival DOI is desired.
